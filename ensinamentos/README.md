# Ensinamentos do DodaiOS

Cada pasta é um pacote pronto de um trabalho que o agente já sabe fazer. Em outra empresa, baixe o pacote, responda às perguntas e use.

| Pasta | O que guarda |
| --- | --- |
| `como fazer` | Passos, telas e cuidados. Serve para qualquer empresa |
| `modelo da empresa` | Perguntas para configurar uma empresa nova |
| `exemplo <empresa>` | Exemplo real, sem dados de pessoas. Não aplicar em outra empresa sem as perguntas |

## Regras para todo ensinamento novo

1. Criar uma pasta aqui com o nome do trabalho, como `analisar email`.
2. Separar o que é geral do que é da empresa.
3. Nunca subir senhas, tokens, proprietários, clientes, telefones, e-mails, fotos ou registros individuais.
4. Atualizar a pasta sempre que o agente aprender algo novo.
