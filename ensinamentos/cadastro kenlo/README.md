# Cadastro no Kenlo

Lê fichas de um grupo do WhatsApp, organiza as fotos, prepara o anúncio e cadastra o imóvel no Kenlo.

## Como implantar em outra imobiliária

1. Instale o DodaiOS e conecte o WhatsApp, o Kenlo e o modelo de imagens.
2. Responda ao arquivo `modelo da empresa/perguntas.md`.
3. Rode `leia os cadastros do kenlo` para conhecer os imóveis da empresa.
4. Aprove as regras propostas.
5. Teste um imóvel de cada tipo antes de liberar o Salvar.

## Sistema diferente do Kenlo

Fichas, fotos e descrição continuam valendo. Os passos de tela precisam de um novo treinamento.
